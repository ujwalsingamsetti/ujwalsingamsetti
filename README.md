> *Traditional RAG fails at multi-hop relationship reasoning. This hybrid engine unites structured graph traversals with dense vector similarity for zero-hallucination precision.*

```mermaid

    UserQuery(["💬 User Query: 'Find competitors acquired by TechCorp'"]) --> Gateway["⚡ FastAPI Gateway"]
    
    subgraph DualRetrievalEngine ["🔍 Hybrid Dual-Retrieval Engine"]
        Gateway --> VectorBranch["🔢 Dense Vector Search<br/><b>Qdrant (768-dim all-mpnet)</b>"]
        Gateway --> GraphBranch["🕸️ Graph Traversal<br/><b>Neo4j 5.x (Cypher APOC)</b>"]
        
        VectorBranch --> SemanticScores["🎯 Top-K Semantic Chunks<br/><i>Similarity: 0.912</i>"]
```

### 🤖 Architecture 02: Autonomous Multi-Agent Swarm with MCP Tools

> *Stateful task execution with LangGraph state machines and Model Context Protocol (MCP) tool routing.*

```mermaid
stateDiagram-v2
    [*] --> SupervisorAgent: User Mission Request
    
    state SupervisorAgent {
        [*] --> ParseIntent
        ParseIntent --> PlanDAG: Formulate Action Steps
    }
    
    SupervisorAgent --> WebSearchAgent: Dynamic Tool Call
    SupervisorAgent --> GraphQueryAgent: Cypher Extraction Call
    SupervisorAgent --> DocumentParserAgent: PyMuPDF / OCR Ingestion
    
    state WebSearchAgent {
        [*] --> ExecuteMCPQuery
        ExecuteMCPQuery --> GroundSources
    }
    
    state GraphQueryAgent {
        [*] --> TraverseNeo4jTriples
        TraverseNeo4jTriples --> EntityMapping
    }
    
    WebSearchAgent --> CriticAgent: Synthesized Facts
    GraphQueryAgent --> CriticAgent: Grounded Triples
    DocumentParserAgent --> CriticAgent: Extracted Chunks
    
    state CriticAgent {
        [*] --> HallucinationEval
        HallucinationEval --> CrossVerify: Confidence Score >= 0.95
    }
    
    CriticAgent --> FinalOutput: Verified Synthesized Artifact
    FinalOutput --> [*]
```
